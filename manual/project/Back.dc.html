BOMB YARD

HOW TO PLAY THIS CART Open bomb-yard.nes in an NES emulator such as Mesen or FCEUX. On a real console, use a flash cart that supports mapper 0 (NROM). No emulator? Open web/bomb-yard.html in a browser for Classic or New enhanced mode (page 8). The source code is at github.com/martin79grahn/bomb-yard-nes.
