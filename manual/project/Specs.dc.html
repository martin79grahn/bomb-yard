NES NES-NROM-256

BOARD NROM-256, mapper 0: no bank switching, no extra chips
PRG ROM 32 KB program, 22 KB of it used
CHR ROM 8 KB graphics, 279 of 512 tiles used
PRG RAM None. No battery, nothing is saved
WORK RAM The console's own 2 KB, all in use: 1.1 KB of game data, the sprite table and the stacks
TV NTSC, 60 Hz. Vertical mirroring
FILE bomb-yard.nes, iNES, 40 KB

The same board as Super Mario Bros., so a flash cart that handles mapper 0 (Everdrive N8, PowerPak) or an NROM-256 board runs it.

MEGA DRIVE 2 MBIT, NO MAPPER

ROM 256 KB (2 Mbit), 208 KB used by code, graphics, music and samples
MAPPER None. The ROM sits flat in the address space
SAVE RAM None. Nothing is saved
WORK RAM The console's own 64 KB; 2.7 KB of game data
VIDEO RAM 901 tiles (28 KB) of the 64 KB
SOUND Z80 with SGDK's XGM2 driver: FM, PSG, samples
REGION JUE (any console), 3-button pad, made for 60 Hz
FILE md/bomb-yard.bin

Any plain cartridge of 2 Mbit or more, or a flash cart such as the Mega Everdrive.
